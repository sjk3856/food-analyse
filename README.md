# 🥗 FoodCare AI (스마트 식품 영양 & 섭취 주의사항 분석기)

음식 사진이나 음식명을 입력받아 **칼로리**, **영양 성분**, **일반 섭취 주의사항**, 그리고 **절대 먹으면 안 되는 사람(특정 질환자, 약물 복용자, 알레르기 유발 대상)**을 전문 임상영양학적 관점에서 정밀 분석해주는 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특장점

1. **멀티모달 비전 & 텍스트 분석 (Gemini Vision AI)**
   - 음식 사진을 드래그 앤 드롭하거나 모바일 카메라로 촬영해 업로드하면 사진 속 음식을 시각적으로 인식합니다.
   - 음식명 텍스트만으로도 즉시 상세 영양과 주의사항을 진단할 수 있습니다.

2. **칼로리 및 영양 성분 시각화**
   - 1인분 기준 예상 칼로리(kcal)와 기준 용량(g) 제공.
   - 탄수화물/당류, 단백질, 지방/포화지방, 나트륨 비율을 시각적 게이지 바로 표시.

3. **이런 분은 섭취를 피하세요! (금기 대상 정밀 진단)**
   - 만성 신장질환(CKD), 당뇨병, 고혈압, 통풍, 비브리오 패혈증 고위험군(간질환자) 등 기저질환별 위험도 분류 (`절대 금기`, `강한 주의`, `섭취 제한`).
   - 의학적 병태생리학적 이유(예: 칼륨 배설 장애, 고칼륨혈증, 요산 배설 억제, 혈당 스파이크) 명시.

4. **치명적 약물 상호작용 경고 (Drug-Food Interaction)**
   - 예: 자몽과 고혈압약(칼슘채널차단제)/고지혈증약(스타틴) 상호작용으로 인한 횡문근융해증 경고 등.

5. **상극 음식 조합 & 건강 섭취 팁**
   - 함께 섭취하면 해로운 음식 조합(예: 간장게장 + 감, 치킨 + 맥주).
   - 조리법 개선 및 채소 곁들임 등 나트륨 배출/혈당 억제 팁.

6. **부가 편의 기능**
   - **TTS(음성 안내)**: 시각 장애인이나 요리 중인 사용자를 위해 분석 결과를 음성으로 낭독.
   - **원클릭 복사**: 결과를 메신저나 메모장에 간편하게 공유할 수 있는 정형화된 텍스트 복사.
   - **로컬 히스토리(최근 기록)**: 브라우저에 최근 20개의 분석 기록 자동 저장 및 재확인.
   - **오프라인/시뮬레이션 모드 지원**: API 키가 없어도 내장된 임상 영양 데이터베이스를 통해 즉시 주요 음식(간장게장, 자몽, 치맥, 마라탕 등) 분석 가능.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 실행 방법
별도의 Node.js나 복잡한 백엔드 서버 설정 없이, **`index.html` 파일을 더블클릭하여 최신 브라우저(Chrome, Safari, Edge 등)에서 바로 실행**할 수 있습니다.

```bash
# 로컬 웹 서버로 열고 싶은 경우 (선택)
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

### 2. Gemini API 키 연동 (선택사항)
1. 우측 상단의 **[API 키 설정]** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급받은 Gemini API 키를 입력하고 저장합니다.
3. API 키는 브라우저의 `localStorage`에만 저장되어 안전합니다.
4. *참고: API 키를 입력하지 않아도 내장된 시뮬레이션 엔진이 작동하여 간장게장, 마라탕, 자몽, 치맥 등의 샘플을 즉시 체험하실 수 있습니다.*

## 💻 기술 스택

| 영역 | 기술 스택 | 설명 |
| :--- | :--- | :--- |
| **Frontend** | HTML5, Vanilla JavaScript | 가볍고 의존성 없는 빠른 반응성 |
| **Styling** | Tailwind CSS (CDN), Pretendard Font | 모던 헬스케어 감성의 모바일 최적화 UI |
| **Icons** | Lucide Icons | 직관적인 인포그래픽 아이콘 |
| **AI Model** | Google Gemini 1.5 Flash (Vision & Text) | 초고속 멀티모달 이미지/텍스트 추론 |
| **Browser APIs**| Web Speech API (TTS), Clipboard API, LocalStorage | 접근성 및 편의성 강화 |
