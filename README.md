# **🥗 FoodCare AI (스마트 푸드케어 AI)**

> **"이 음식, 내가 먹어도 괜찮을까?"**

> 음식 사진 또는 이름만으로 **칼로리**, **영양 성분**, **섭취 주의사항**, 그리고 \*\*절대 먹으면 안 되는 사람(만성질환·약물 상호작용)\*\*을 즉시 진단하는 멀티모달 식이 안전 닥터 웹 애플리케이션입니다.

## **📌 프로젝트 소개**

현대인은 당뇨, 고혈압, 통풍, 만성 신부전 등의 기저질환을 앓고 있거나 특정 전문의약품(혈압약, 고지혈증약, 항응고제 등)을 상시 복용하는 경우가 많습니다. 일반인에게는 건강식이나 별미인 음식(예: 간장게장, 자몽, 시금치, 치맥 등)이 특정 환자에게는 치명적인 급성 쇼크나 부작용을 일으킬 수 있습니다.

**FoodCare AI**는 스마트폰 카메라 촬영 또는 간단한 텍스트 입력만으로 식품의 영양 정보는 물론, **의학적 관점의 섭취 금기 대상**과 **약물 상호작용 위험**을 실시간으로 분석하여 직관적으로 제공합니다.

## **✨ 핵심 기능**

### **1\. 📷 멀티모달(사진 \+ 텍스트) 간편 분석**

* **스마트폰 맞춤 이미지 리사이징**: 고화질 카메라 원본 사진을 브라우저 캔버스에서 가볍게 자동 압축(최대 960px)하여 데이터 소모 없이 빠른 분석을 지원합니다.  
* **사진 단독 / 텍스트 단독 지원**: 사진만 업로드하거나 텍스트(예: "간장게장", "마라탕")만 입력해도 동일하게 정밀 분석을 수행합니다.

### **2\. 🚫 의학적 금기 대상 & 약물 상호작용 진단 (핵심)**

* **질환별 섭취 금기 진단**: 만성 신부전(CKD, 고칼륨·고나트륨), 통풍(퓨린), 당뇨(혈당 스파이크), 역류성 식도염 등 질환별 위험군을 추출하고 명확한 의학적 이유를 제공합니다.  
* **약물 충돌 경고**: 고혈압약(칼슘채널차단제), 고지혈증약(스타틴), 혈액응고억제제(와파린) 등 복용 중인 약물과의 위험한 상호작용을 경고합니다.

### **3\. 📊 칼로리 및 주요 영양 성분 카드**

* 1인분 제공량 기준 칼로리(kcal), 탄수화물/당류, 단백질/지방, 나트륨(mg) 함량 지표 시각화  
* 식단 조절을 위한 맞춤 한 줄 영양 팁 제공

### **4\. ⚡ 상극 음식 & 건강한 대체 조리법**

* 함께 섭취하면 부작용을 일으키는 상극 음식 궁합 제시 (예: 게장 \+ 감, 치킨 \+ 맥주)  
* 나트륨 배출을 돕거나 혈당을 완만하게 하는 실천형 조리/섭취 가이드 제공

### **5\. 🔊 접근성 및 편의 기능**

* **TTS 음성 안내 (Web Speech API)**: 고령층 및 시각 약자를 위해 핵심 분석 결과를 한국어 음성으로 낭독  
* **결과 클립보드 복사**: 가족, 지인, 환자에게 메신저로 간편하게 공유할 수 있는 텍스트 포맷 복사  
* **최근 분석 히스토리**: localStorage 기반 최근 분석 15개 자동 저장 및 복원 기능  
* **개인 API 키 보안 저장**: 사용자의 Gemini API 키는 외부 서버가 아닌 개인 브라우저 내부에만 안전하게 보관

## **🛠️ 기술 스택**

| 분류 | 사용 기술 | 설명 |
| :---- | :---- | :---- |
| **Frontend** | HTML5, Vanilla JavaScript | 별도의 빌드 단계 없는 경량 단일 파일(SPA) 아키텍처 |
| **Styling** | Tailwind CSS (CDN), Pretendard Font | 모바일 반응형 및 현대적인 모던 헬스케어 UI |
| **Icons** | Lucide Icons | 간결하고 직관적인 SVG 아이콘 세트 |
| **AI Engine** | Google Gemini API (gemini-1.5-flash / gemini-3-flash) | 멀티모달 비전 인식 및 실시간 JSON 정형 데이터 추론 |
| **Storage** | Web Storage API (localStorage) | 최근 검색 기록 및 API 키 로컬 보관 |
| **Audio** | Web Speech Synthesis API | 브라우저 내장 음성 합성(TTS) |

## **🚀 실행 방법**

본 프로젝트는 별도의 Node.js 설치, 패키지 빌드(npm install) 과정 없이 **웹 브라우저에서 파일 하나로 즉시 실행**할 수 있습니다.

### **방법 1: 브라우저로 바로 열기**

1. 본 저장소의 index.html 파일을 다운로드합니다.  
2. 다운로드한 index.html을 더블 클릭하거나 Chrome, Safari, Edge 등의 브라우저 창으로 드래그하여 엽니다.

### **방법 2: 로컬 웹 서버 실행 (선택)**

\# Python 내장 서버 활용 시  
python3 \-m http.server 8080

\# 브라우저에서 접속  
http://localhost:8080

## **🔑 Gemini API 키 발급 및 등록**

1. [Google AI Studio](https://aistudio.google.com/)에 접속하여 무료 API 키를 발급받습니다.  
2. 상단 헤더 우측의 **\[API 설정\]** 버튼을 클릭합니다.  
3. 발급받은 API 키(AIzaSy...)를 입력하고 \[저장하기\]를 누르면 연동이 완료됩니다.

> *API 키가 등록되지 않은 상태에서도 기본 내장 시뮬레이션 지식 베이스를 통해 예시 음식들을 테스트해보실 수 있습니다.*
